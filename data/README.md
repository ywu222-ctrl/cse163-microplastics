# Data

`NOAA_0253923_original.xlsx` is the unchanged workbook from NOAA NCEI
accession 0253923. It contains 124 measurements in `MP_data_S2N` and column
definitions in `Data_Dictionary`. The analysis reads this copy from `data/`.

The identical workbook in the repository root provides the download link
used in the report. It is a second copy of the same dataset.
